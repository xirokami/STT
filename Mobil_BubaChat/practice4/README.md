StringManipulator
Описание: 
Класс для выполнения операций со строками.

Функции:
reversed_string - Переворачивает строку
to_uppercase - Переводит строку в верхний регистр
to_lowercase - Переводит строку в нижний регистр

| Тестовые случаи | Входные данные | Выходные данные |
|-----------|:------------:|------------:|
| Переворот строки   |   hello   |    olleh |
| Перевод строки в ве|   Fight   |    FIGHT |
| рхний регистр      |           |          |
| Перевод строки в ни| MEGAZOOM  | megazoom |
| жний регистр       |           |          |
