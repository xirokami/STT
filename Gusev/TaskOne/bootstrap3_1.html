Twitter bootstrap - свободный набор инструментов для создания сайтов и веб-приложений.Включает в себя HTML и CSS шаблоны оформления для типографики, веб-формы, кнопки, меток, блоков навигации и прочих компонентов веб-интерфейсов включая JavaScript разширение. Bootstrap использует самые современные наработки в области CSS и HTML, Поэтому необходимо быть внимательным при поддержке старых браузеров
