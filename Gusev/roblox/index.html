Наши преимущества

🚀 Быстрота

Элементы появляются плавно, как только вы до них доскроллили.

🎨 Гибкость

Меняйте стили, задержки и направления анимации под свой дизайн.

⚡ Легкость

Работает на чистом JS без библиотек, быстро и отзывчиво.

🔄 Анимация из левого края

Этот блок выезжает слева, когда попадает в область видимости. Вы можете комбинировать разные типы анимации: снизу вверх, слева направо, масштабирование и т.д.

Ключевые особенности технологии

📐 Intersection Observer

Используется современный API браузера — производительность отличная, события скролла не тормозят страницу.

🎯 Точный порог срабатывания

Можно настроить, при какой видимости элемента (20%, 50% и т.д.) запускать анимацию.

♻️ Повторная анимация

По умолчанию анимация срабатывает один раз. Но при желании легко сделать так, чтобы эффект повторялся при каждом появлении.

💡 Как это работает?

1. Все элементы, которые должны анимироваться, получают класс .scroll-animate (или .scroll-animate-left).
2. При загрузке страницы создаётся Intersection Observer, который следит за этими элементами.
3. Когда элемент хотя бы на 20% показывается во вьюпорте, ему добавляется класс .revealed — и CSS уже делает его видимым.
4. Вы можете настроить порог, направление и тип анимации в CSS.

Анимация появляется только один раз для каждого элемента. Листайте вверх/вниз — новые элементы будут раскрываться по очереди.
